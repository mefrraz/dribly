## O que foi feito na v12

### Estrutura
- **Capacitor Android**: projeto gerado em `android/`, WebView carrega `https://dribly.pt`, auto-update via deploy Vercel. Ícones copiados de `assets/app-icons/`. APK pendente de rebuild.
- **Fonte Outfit self-hosted**: via `@fontsource/outfit`, removida dependência Google Fonts

### Página `/inicio` — App de resultados
Arquivo: `web/src/pages/Home.tsx` (~500 linhas)

**Data flow:**
- Busca 7 ligas (4 masc + 3 fem) via `/api/fpb?page=calendario&competicao={id}` e `resultados`
- 14 pedidos HTTP em paralelo (~2s)
- Parse do HTML da FPB feito no cliente (`parseFPBHtml`)
- Cache inteligente via `localStorage`: guarda por data, re-fetch só quando último jogo + 2h passou

**UI:**
- Blur roxo atrás da navbar
- League pills (Liga Betclic, Proliga, 1ª Divisão) com logos
- Barra de pesquisa (abre overlay)
- Date selector: Ontem | Hoje | Amanhã + 3 dias + 📅 date picker
- Featured GameCard (liga mais alta)
- Accordions por competição (sem corações, sem contadores)

**Seguidos (parcialmente funcional):**
- `useEffect` separado com `useRef` para evitar loop infinito
- Busca `/api/fpb?page=calendario&clube={id}` para cada clube seguido (até 8)
- Filtra por `selectedDate`
- Accordion "Seguidos" aparece se `followedClubIds.length > 0`
- Enquanto carrega: "A pesquisar jogos..." com spinner
- Cada row mostra o nome da competição (`showCompetition`)
- **Problema conhecido:** `parseFPBHtml(html, '')` passa competição vazia — os jogos aparecem mas sem nome de competição

### Smart Landing
